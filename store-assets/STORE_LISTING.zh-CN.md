# Chrome Web Store 商店文案（zh-CN）

## 名称

枝句 · 生图词库收录器

## 摘要

从网页右键收录视觉描述，在浏览器本地整理、审核、搜索并一键复制 Prompt。

## 详细描述

枝句是一款完全在浏览器本地运行的生图 Prompt 收录器。选中网页里的视觉描述后，通过右键菜单保存到侧栏，再将完整描述整理为可复用的原子词、组合配方或常用 Prompt。

主要功能：

- 网页选中文字后一键收录
- 原文原样保存到扩展 IndexedDB
- 原子词、组合配方与常用 Prompt 分层管理
- 搜索、分类、复制次数和一键复制
- 人工审核后才进入正式词库
- JSON 备份导入与导出
- 无账号、无配套服务、无需配对
- 不上传正文，不连接开发者或第三方服务器

安装后直接打开扩展侧栏即可使用。
