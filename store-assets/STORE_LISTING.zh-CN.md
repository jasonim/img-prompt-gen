# Chrome Web Store 商店文案（zh-CN）

## 名称

枝句 · 生图词库收录器

## 摘要

从网页右键收录视觉描述，在本地整理、审核、搜索并一键复制 Prompt。

## 详细描述

枝句是一款本地优先的生图 Prompt 收录器。选中网页里的视觉描述后，通过右键菜单保存到侧栏，再将完整描述整理为可复用的原子词、组合配方或常用 Prompt。

主要功能：

- 网页选中文字后一键收录
- 离线暂存，服务恢复后自动重试
- 原子词、组合配方与常用 Prompt 分层管理
- 搜索、分类、复制次数和一键复制
- 人工审核后才进入正式词库
- 数据仅保存在用户自己的设备上

当前版本需要配套的枝句本地服务。安装后请按照项目提供的安装说明启动服务并完成一次性配对。
