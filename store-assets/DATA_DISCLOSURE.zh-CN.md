# Chrome Web Store 隐私与权限填报

## 单一用途

从网页右键收录用户主动选择的视觉描述，并在同一设备上的本地词库中整理、审核、搜索和复制 Prompt。

## 权限理由

- `contextMenus`：仅在用户选中文字后显示“保存到生图词库”右键菜单，这是扩展的主要收录入口。
- `storage`：在浏览器本地保存离线暂存、配对状态和复制次数；正文同步成功后不会长期保留在浏览器存储中。
- `sidePanel`：在 Chrome 侧边栏提供词库浏览、人工审核、整理和编辑界面。
- `clipboardWrite`：仅在用户明确点击“复制”按钮时把选定 Prompt 写入剪贴板。
- `http://127.0.0.1/*`：仅连接用户自己设备上的枝句服务。服务固定监听回环地址，不接受局域网或公网连接。

## 远程代码

不使用远程代码。所有 JavaScript 均包含在扩展 ZIP 内；内容安全策略只允许 `script-src 'self'`，未使用 `eval`、远程脚本或 WebAssembly。

## 用户数据类型

- 网站内容：是。仅处理用户主动选中的网页文字。
- 浏览记录：否。不读取或保存网页 URL、页面标题或完整浏览历史。
- 身份验证信息：否。一次性配对密钥和本地 Token 只用于同一设备上的服务认证，不会发送给开发者。
- 个人身份信息、财务信息、健康信息、位置、通信内容：否。

## 数据处理声明

- 不向开发者或第三方服务器传输用户数据。
- 不出售用户数据，不用于广告、信用评估或与单一用途无关的用途。
- 不允许人工读取用户数据。
- 数据仅保存在用户设备上，用户可删除单条记录或整个本地数据目录。
- 遵守 Chrome Web Store 用户数据政策的有限使用要求。
