# 枝句 · 本地生图词库

一个完全运行在 Chrome 扩展内的 Manifest V3 生图 Prompt 词库：网页右键收录，侧栏整理、审核、搜索与复制，数据保存在扩展自己的 IndexedDB 中。

## 使用要求

- Google Chrome 116 或更新版本。
- 不需要 Node.js、本地服务、数据库、账号或云服务。

## 安装

开发版：

1. 打开 `chrome://extensions`。
2. 开启“开发者模式”。
3. 点击“加载未打包的扩展程序”。
4. 选择项目中的 `extension/` 目录。
5. 打开“枝句”侧栏；首次打开即可使用，无需配对。

商店版安装后直接打开扩展侧栏即可。

## 收录、整理与批准

1. 在普通网页中选中文字。
2. 右键选择“保存到生图词库”。原文会原样写入扩展 IndexedDB。
3. 在“待整理”中拆成原子词，并可保留组合配方与完整 Prompt。
4. 机器校验与人工审核是两件事；只有明确点击“人工批准”的当前内容才进入正式词库。
5. 编辑已批准内容会撤销批准；编辑原子词还会撤销依赖它的已批准配方。

## 备份与迁移

在侧栏“保存记录”中：

- “导出备份”下载完整 JSON 备份。
- “导入备份”先验证结构、审核哈希和引用关系，再以单个 IndexedDB 事务替换当前词库。

导入会替换当前词库，操作前请先导出。备份包含原始 Prompt 正文，请存放在可信位置。

## 开发验证与打包

需要 Node.js 22–24，仅用于开发测试和生成 ZIP，不是扩展运行依赖。

```bash
npm install
npm run verify
```

`verify` 包含产品契约、语法、自动化测试、80% 覆盖率门禁和发布包生成。产物：

- `dist/zhiju-web-store-v0.2.0.zip`：Chrome Web Store 上传包，`manifest.json` 位于 ZIP 根目录。
- `dist/zhiju-prompt-collector-v0.2.0.zip`：无需商店的“加载未打包”分发包。

`server/`、`data/` 和相关脚本仅保留为 0.1.x 本地服务版本的迁移参考，不进入 0.2.x 发布包。旧版回归可单独运行 `npm run test:legacy-server`。

## 隐私边界

- 只保存用户主动选中或输入的文字、时间、审核状态和追溯 ID。
- 不保存网页 URL、标题、HTML、Cookie、账号、浏览历史或剪贴板历史。
- 不连接开发者或第三方服务器，不使用远程模型或远程代码。
- 卸载扩展会由 Chrome 删除该扩展的 IndexedDB；卸载前请先导出备份。
