# 枝句 · 安装说明

## 准备

- Google Chrome 116 或更高版本。
- 不需要 Node.js、本地服务、账号或配对密钥。

## 安装 Chrome 扩展

1. 解压下载包。
2. 打开 `chrome://extensions`。
3. 开启右上角“开发者模式”。
4. 点击“加载未打包的扩展程序”。
5. 选择解压目录中的 `extension` 文件夹。
6. 打开“枝句”侧栏即可使用。

## 使用与备份

在网页上选中文字，右键选择“保存到生图词库”。内容会写入扩展自己的 IndexedDB，并进入“待整理”；人工整理并批准后出现在正式词库。

侧栏“保存记录”提供 JSON 备份的导入和导出。导入会替换当前词库，请先导出备份。卸载扩展前也请先导出，因为 Chrome 会删除该扩展的本机数据。
