# 枝句 · 安装说明

## 准备

- Google Chrome 116 或更高版本。
- Node.js 22 或 24 LTS：<https://nodejs.org/>

本软件不需要数据库、云账号或第三方 npm 依赖。

## 启动本地服务

- macOS：双击 `启动服务.command`。
- Windows：双击 `启动服务-Windows.cmd`。
- 也可以在当前目录运行 `npm start`。

终端会显示一条 10 分钟有效的一次性配对密钥。服务仅监听本机 `127.0.0.1:43119`。

## 安装 Chrome 扩展

1. 打开 `chrome://extensions`。
2. 开启右上角“开发者模式”。
3. 点击“加载未打包的扩展程序”。
4. 选择本目录中的 `extension` 文件夹。
5. 打开“枝句”侧栏，输入终端显示的配对密钥。

## 使用

在网页上选中文字，右键选择“保存到生图词库”。内容会进入“待整理”，人工整理并批准后出现在正式词库。

如果重新安装扩展后无法连接，在服务目录运行 `npm run pairing:reset`，使用新密钥重新配对。
