# Organizing protocol

Preserve the original capture first. Then ask one question for each candidate phrase:

> Does this phrase contain two or more visible image-control mechanisms that could be independently added, removed, replaced, or locked?

- If no, it may be a term even when it is moderately long.
- If yes, split by control mechanism or preserve the relationship as a recipe.
- Never split mechanically by comma count, character count, tag count, or source heading.
- Check normalized existing names before adding a synonym.
- Judge browsing category and visual responsibility independently.
- If either judgment is uncertain, leave the content pending or mark it needs revision.
- Keep a derived full Prompt with its recipe; do not copy it into common prompts.
- Machine validation is not human approval. Only the local user's explicit approval publishes content.
